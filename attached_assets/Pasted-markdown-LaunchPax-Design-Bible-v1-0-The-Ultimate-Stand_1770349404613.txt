# LaunchPax Design Bible v1.0
## The Ultimate Standard for Creating "WOW" Websites

---

## PHILOSOPHY: BEYOND GOOD, INTO WOW

**Good websites are forgettable. WOW websites are unforgettable.**

This isn't a guide for "decent" or "professional-looking" websites. This is the bible for creating websites that make users stop scrolling, lean forward, and say "damn, this is beautiful."

Every website generated by LaunchPax must pass the **10-Second Rule**:
> If a user doesn't feel something (excitement, curiosity, trust, desire) within 10 seconds of landing, we failed.

---

## SECTION 1: THE WOW FACTOR FRAMEWORK

### What Makes a Website "WOW"?

**WOW = Visual Impact × Emotional Resonance × Unexpected Delight**

#### Visual Impact (The Gasp)
- First 0.5 seconds: User's eyes widen
- Typography so bold it demands attention
- Color combinations that feel *alive*
- Whitespace that breathes luxury
- Images that look like art, not stock photos

#### Emotional Resonance (The Connection)
- Copy that speaks to ONE person, not "everyone"
- Stories that feel real, not corporate
- Personality that shines through every word
- Benefits that make users think "this is for ME"

#### Unexpected Delight (The Smile)
- Micro-interactions that feel playful
- Scroll reveals that surprise
- Details users don't expect but love
- Moments that make them want to share

## SECTION 2: THE 7 PILLARS OF WOW DESIGN

### PILLAR 1: HERO SECTIONS THAT HIT LIKE A TRUCK

**Rule:** If your hero section doesn't make someone say "what IS this?", start over.

#### Non-Negotiable Hero Requirements

**Visual Dominance:**
- **90vh minimum height** - Fill the screen, own the space
- **Bold typography** - H1 should be 64px+ on desktop, weight 800+
- **High-contrast** - Text must be instantly readable from 6 feet away
- **Dynamic background** - Gradient overlays, animated gradients, or cinematic photos
- **Zero generic stock photos** - No laptop on desk, no diverse team high-fiving

**Typography Hierarchy:**
```
H1 (Hero Headline):
- Size: 64-96px (desktop), 40-56px (mobile)
- Weight: 700-900
- Line height: 1.1-1.2
- Letter spacing: -0.02em to -0.04em (tighter = more premium)
- Max width: 20 characters per line

Subheadline:
- Size: 20-28px (desktop), 18-22px (mobile)  
- Weight: 400-500
- Line height: 1.5-1.6
- Opacity: 0.8-0.9 (slightly muted for hierarchy)
- Max width: 60 characters per line
```

**Color Contrast Standards:**
- Light text on dark: minimum 15:1 contrast ratio
- Dark text on light: minimum 12:1 contrast ratio
- Use WebAIM contrast checker - if it's not AAA, reject it

**Background Treatment:**
- **Gradient overlays** - 40-60% opacity, multi-stop gradients
- **Depth** - Multiple layers (background image + gradient + particle effects)
- **Motion** - Subtle animated gradients (5-8 second loops)
- **Focus** - Directional blur that draws eye to headline

#### Hero Archetypes (Use These, Not Generic Templates)

**1. The Challenger**
```
Visual: Bold, high-contrast, aggressive gradients
Typography: Extra bold (800-900), tight letter-spacing
Colors: High saturation, neon accents
Mood: "We're not like them"
Example: Dark background, electric blue/purple gradient, white bold sans-serif
```

**2. The Luxury**
```
Visual: Maximum whitespace, elegant serif typography
Typography: Light weight (300-400) with large size (80px+)
Colors: Monochrome with gold/champagne accents
Mood: "You deserve this"
Example: Cream background, subtle warm gradient, editorial serif
```

**3. The Technical**
```
Visual: Grid systems, geometric shapes, terminal aesthetics
Typography: Monospace accents, medium weight (500-600)
Colors: Dark mode, terminal green, blue accents
Mood: "Built by experts"
Example: Dark navy, code-style elements, glowing accents
```

**4. The Human**
```
Visual: Large portrait photos, warm tones, real moments
Typography: Friendly sans-serif, approachable weight (500)
Colors: Warm, earthy, organic palette
Mood: "We're just like you"
Example: Warm beige, founder photo, handwritten-style accents
```

**5. The Futuristic**
```
Visual: Glass morphism, 3D elements, holographic effects
Typography: Wide geometric sans-serif, bold
Colors: Iridescent gradients, cyber blues/purples
Mood: "Welcome to tomorrow"
Example: Deep space blue, aurora gradient, glowing edges
```

**WOW Hero Checklist:**
- [ ] Hero is 90vh or taller (not 60vh, not 70vh - NINETY)
- [ ] Headline is 64px+ and bold (700+ weight)
- [ ] Background has 3+ layers (image + gradient + effect)
- [ ] Text contrast ratio is 15:1 or higher
- [ ] CTA button has hover animation (not just color change)
- [ ] Scroll indicator is present (arrow, text, or animated icon)
- [ ] No generic stock photos (no laptops, no stock business people)
- [ ] Typography uses proper letter-spacing (-0.02em minimum)
- [ ] Subheadline is muted (80-90% opacity) for hierarchy
- [ ] Mobile version is equally impactful (not just scaled down)

### PILLAR 2: TYPOGRAPHY THAT COMMANDS ATTENTION

**Rule:** Typography should feel intentional, not default.

#### Font Selection Standards

**NEVER use these (instant mediocrity signals):**
- ❌ Arial / Helvetica (unless ironic)
- ❌ Times New Roman
- ❌ Calibri / Cambria
- ❌ Comic Sans (obviously)
- ❌ Papyrus (why would you even)

**Premium Font Combinations:**

**Modern Tech:**
```
Headings: Inter (700-900), Archivo (800), Space Grotesk (700)
Body: Inter (400-500), Work Sans (400)
Accent: JetBrains Mono (for code/tech elements)
```

**Elegant Professional:**
```
Headings: Playfair Display (700), Cormorant Garamond (600)
Body: Lora (400), Crimson Text (400)
Accent: Cinzel (for luxury touch)
```

**Bold Startup:**
```
Headings: Outfit (800), Sora (800), Manrope (800)
Body: DM Sans (400), Plus Jakarta Sans (400)
Accent: Space Mono (700)
```

**Creative Agency:**
```
Headings: Fraunces (900), Archivo Black (400)
Body: Commissioner (400), Public Sans (400)
Accent: Orbitron (for tech flair)
```

#### Typography Scale (Never Break This)
```css
/* Mobile First */
--text-xs: 0.75rem;    /* 12px - captions, metadata */
--text-sm: 0.875rem;   /* 14px - small body text */
--text-base: 1rem;     /* 16px - body text */
--text-lg: 1.125rem;   /* 18px - large body */
--text-xl: 1.25rem;    /* 20px - subheadlines */
--text-2xl: 1.5rem;    /* 24px - H4 */
--text-3xl: 2rem;      /* 32px - H3 */
--text-4xl: 2.5rem;    /* 40px - H2 mobile */
--text-5xl: 3.5rem;    /* 56px - H1 mobile */

/* Desktop (md breakpoint and up) */
--text-4xl-desktop: 3rem;    /* 48px - H2 */
--text-5xl-desktop: 4rem;    /* 64px - H1 */
--text-6xl-desktop: 5rem;    /* 80px - Hero H1 */
--text-7xl-desktop: 6rem;    /* 96px - Mega Headlines */
```

#### Typography Spacing Rules

**Line Height:**
- Headlines (H1-H3): 1.1 - 1.2 (tighter = more impactful)
- Subheadlines: 1.3 - 1.4
- Body text: 1.5 - 1.7 (generous for readability)
- Small text: 1.4 - 1.5

**Letter Spacing:**
- Large headlines (64px+): -0.035em to -0.045em (tighter)
- Medium headlines (32-48px): -0.02em to -0.03em
- Body text (16-18px): 0em (default)
- Uppercase text: +0.05em to +0.1em (always space out caps)
- Button text: +0.02em (subtle tracking)

**Paragraph Spacing:**
- Between paragraphs: 1.5em - 2em
- After headlines: 0.75em - 1em
- Maximum line length: 70 characters (for body text)
- Minimum line length: 45 characters

**WOW Typography Checklist:**
- [ ] Headings use 700+ weight (not 400 or 500 - BOLD)
- [ ] Letter-spacing on large headlines is negative (tighter)
- [ ] Line height on headlines is 1.2 or less
- [ ] Body text line-height is 1.6 or higher
- [ ] No more than 2 font families per website
- [ ] All uppercase text has increased letter-spacing (+0.05em minimum)
- [ ] Font weights have clear hierarchy (900 → 700 → 500 → 400)
- [ ] Mobile headings scale down proportionally (not just smaller)
- [ ] No orphans (single words on last line of paragraph)
- [ ] Text contrast meets AAA standards (7:1 minimum for body)

### PILLAR 3: COLOR THAT EVOKES EMOTION

**Rule:** Colors should make users FEEL something, not just look "nice."

#### Color Psychology by Industry

**Tech/SaaS:**
- Primary: Deep Blues (#1E40AF, #3B82F6) - Trust, innovation
- Accent: Electric Cyan (#06B6D4, #22D3EE) - Energy, cutting-edge
- Avoid: Reds (too aggressive), Pastels (too soft)

**Finance/Legal:**
- Primary: Navy (#1E3A8A), Slate (#334155) - Authority, stability
- Accent: Gold (#F59E0B), Emerald (#10B981) - Success, growth
- Avoid: Neon colors (unprofessional), Bright reds (alarm)

**Healthcare/Wellness:**
- Primary: Calming Teal (#14B8A6), Soft Blue (#3B82F6) - Trust, healing
- Accent: Sage Green (#84CC16), Warm Coral (#FB923C) - Health, vitality
- Avoid: Harsh reds (medical emergency), Dark grays (depressing)

**Creative/Agency:**
- Primary: Bold Magenta (#DB2777), Deep Purple (#7C3AED) - Creative, bold
- Accent: Vibrant Orange (#F97316), Electric Yellow (#FACC15) - Energy
- Avoid: Corporate blues (boring), Beiges (safe)

**E-commerce/Retail:**
- Primary: Confident Red (#DC2626), Rich Purple (#9333EA) - Desire, luxury
- Accent: Gold (#F59E0B), Bright Teal (#14B8A6) - Value, trust
- Avoid: Too many colors (chaotic), Muddy browns (cheap)

**Food/Hospitality:**
- Primary: Warm Orange (#EA580C), Rich Red (#DC2626) - Appetite, warmth
- Accent: Olive Green (#84CC16), Creamy Yellow (#FDE047) - Fresh, organic
- Avoid: Blues/purples (suppress appetite), Grays (sterile)

#### Advanced Color Systems

**Gradient Overlays (The Secret Sauce):**

Every background image MUST have a gradient overlay. Period.

**Formula:**
```css
background: linear-gradient(
  [angle]deg,
  [color-1] [stop-1]%,
  [color-2] [stop-2]%,
  [color-3] [stop-3]%
);
```

**Premium Gradient Recipes:**

**Tech Startup:**
```css
/* Aurora Gradient */
background: linear-gradient(
  135deg,
  rgba(99, 102, 241, 0.9) 0%,
  rgba(139, 92, 246, 0.8) 50%,
  rgba(236, 72, 153, 0.7) 100%
);
```

**Luxury Brand:**
```css
/* Gold Dusk */
background: linear-gradient(
  180deg,
  rgba(0, 0, 0, 0.6) 0%,
  rgba(120, 53, 15, 0.5) 50%,
  rgba(217, 119, 6, 0.4) 100%
);
```

**Health/Wellness:**
```css
/* Calm Waters */
background: linear-gradient(
  120deg,
  rgba(6, 182, 212, 0.85) 0%,
  rgba(16, 185, 129, 0.75) 100%
);
```

**Dark Mode Excellence:**
```css
/* Cyber Night */
background: linear-gradient(
  225deg,
  rgba(15, 23, 42, 0.95) 0%,
  rgba(30, 41, 59, 0.9) 50%,
  rgba(51, 65, 85, 0.85) 100%
);
```

#### Color Accessibility Standards

**Contrast Ratios (WCAG AAA):**
- Large text (18px+): 4.5:1 minimum
- Body text (16px): 7:1 minimum  
- Headings (24px+): 7:1 minimum
- Interactive elements: 3:1 minimum (against background)

**Never Rely on Color Alone:**
- Buttons: color + icon + text
- Links: color + underline
- Alerts: color + icon + border
- Status: color + badge + text

**WOW Color Checklist:**
- [ ] Primary color evokes correct emotion for industry
- [ ] Color palette has 3-5 colors maximum (not 10+)
- [ ] Every background image has gradient overlay (40-70% opacity)
- [ ] Gradients use 3+ color stops (not just 2)
- [ ] Text contrast meets AAA standards (7:1 for body)
- [ ] Dark mode uses true blacks (#000) sparingly (use #0F172A instead)
- [ ] Accent colors are vibrant (saturation 60%+)
- [ ] No pure black text on white (use #1F2937 on #FFFFFF)
- [ ] Hover states darken/lighten by 10-15% (noticeable change)
- [ ] Color system is consistent across all sections

### PILLAR 4: SPACING THAT BREATHES LUXURY

**Rule:** Luxury brands use 2-3x more whitespace than budget brands.

#### Spacing Scale (8px Base Unit)
```css
/* Never use arbitrary values - stick to this scale */
--space-1: 0.25rem;   /* 4px */
--space-2: 0.5rem;    /* 8px */
--space-3: 0.75rem;   /* 12px */
--space-4: 1rem;      /* 16px */
--space-5: 1.25rem;   /* 20px */
--space-6: 1.5rem;    /* 24px */
--space-8: 2rem;      /* 32px */
--space-10: 2.5rem;   /* 40px */
--space-12: 3rem;     /* 48px */
--space-16: 4rem;     /* 64px */
--space-20: 5rem;     /* 80px */
--space-24: 6rem;     /* 96px */
--space-32: 8rem;     /* 128px */
```

#### Section Spacing Rules

**Vertical Rhythm:**
```
Hero Section: 
  - Padding top: --space-20 (80px mobile), --space-32 (128px desktop)
  - Padding bottom: --space-20 (80px mobile), --space-32 (128px desktop)
  - Internal spacing (headline to CTA): --space-8 (32px)

Content Sections:
  - Padding top: --space-16 (64px mobile), --space-24 (96px desktop)
  - Padding bottom: --space-16 (64px mobile), --space-24 (96px desktop)
  - Between sections: --space-12 to --space-16 (48-64px)

Cards/Feature Blocks:
  - Internal padding: --space-6 to --space-8 (24-32px)
  - Gap between cards: --space-6 (24px mobile), --space-8 (32px desktop)
  - Card to edge margin: --space-4 (16px minimum)
```

**Horizontal Rhythm:**
```
Container Max Width:
  - Text content: 65ch (65 characters)
  - Mixed content: 1280px
  - Full-bleed: 1440px
  - Ultra-wide: 1600px

Gutters:
  - Mobile: --space-4 to --space-6 (16-24px)
  - Tablet: --space-8 (32px)
  - Desktop: --space-12 to --space-16 (48-64px)

Grid Gaps:
  - Tight: --space-4 (16px)
  - Normal: --space-6 to --space-8 (24-32px)
  - Loose: --space-12 (48px)
```

#### Premium Spacing Principles

**The Breath Test:**
> If a section feels cramped when you take a deep breath while looking at it, it needs more space.

**Spacing Hierarchy:**
1. **Micro** (4-12px): Between related elements (icon + text, label + input)
2. **Macro** (24-48px): Between section components (headline block + content)
3. **Mega** (64-128px): Between major sections (hero → features → testimonials)

**Luxury Spacing Formula:**
- Budget brand spacing: 1x
- Professional brand spacing: 1.5x
- Premium brand spacing: 2x
- **WOW brand spacing: 2.5-3x**

**WOW Spacing Checklist:**
- [ ] Sections have 96px+ vertical padding on desktop
- [ ] Headlines have 32px+ margin below them
- [ ] Cards/blocks have 24px+ internal padding
- [ ] Grid gaps are 32px+ on desktop
- [ ] Container max-width for text is 65ch or less
- [ ] No elements touch the edge (minimum 16px margin)
- [ ] Spacing uses 8px grid system (no 13px, 27px random values)
- [ ] Mobile spacing is 60-70% of desktop (not 100%)
- [ ] CTA buttons have 48px+ margin above and below
- [ ] Footer has 80px+ padding top on desktop

### PILLAR 5: IMAGERY THAT TELLS STORIES

**Rule:** Every image must earn its place or be deleted.

#### Image Selection Standards

**BANNED Image Types (Instant Rejection):**
- ❌ Generic stock photos (laptop on desk, diverse team in meeting)
- ❌ Cheesy handshakes
- ❌ People pointing at whiteboards
- ❌ "Casual Friday" office shots
- ❌ Forced diversity stock photos (you know the ones)
- ❌ Anyone jumping in the air with briefcases
- ❌ Light bulbs (idea metaphors)
- ❌ Puzzle pieces (teamwork metaphors)
- ❌ Chess pieces (strategy metaphors)
- ❌ Arrows pointing up (growth metaphors)

**Premium Image Categories:**

**Cinematic Photography:**
- High contrast, dramatic lighting
- Shallow depth of field (blurred backgrounds)
- Golden hour or blue hour shots
- Motion blur for dynamism
- Grain/texture for character

**Abstract/Artistic:**
- Gradients and color fields
- Geometric patterns
- Macro photography (textures, materials)
- Liquid/fluid motion
- Light trails and long exposures

**Authentic Moments:**
- Real candid shots (not posed)
- Close-up details (hands working, tools, materials)
- Environmental portraits (person in their element)
- Product in use (real usage, not staged)
- Behind-the-scenes documentation

**Custom Illustrations:**
- Brand-specific icon sets
- Decorative elements (blobs, shapes, lines)
- Infographic components
- Pattern backgrounds
- Spot illustrations for personality

#### Image Treatment Standards

**Every Image Must Have:**

**1. Proper Aspect Ratios:**
```
Hero images: 16:9 (landscape) or 4:3 (more cinematic)
Portrait images: 3:4 or 9:16
Square images: 1:1 (for testimonials, team)
Wide banners: 21:9 or 3:1
```

**2. Optimization:**
- WebP format with JPEG fallback
- Lazy loading for below-fold images
- Responsive srcset for different screen sizes
- Maximum file size: 200KB (compressed)
- Use CDN (Cloudinary) for automatic optimization

**3. Overlay Treatment:**
```css
/* Subtle Darken (for readability) */
.image-overlay {
  position: relative;
}
.image-overlay::after {
  content: '';
  position: absolute;
  inset: 0;
  background: linear-gradient(
    180deg,
    rgba(0,0,0,0.3) 0%,
    rgba(0,0,0,0.6) 100%
  );
}

/* Color Tint (brand consistency) */
.image-overlay-tint::after {
  background: linear-gradient(
    135deg,
    rgba(59,130,246,0.5) 0%,
    rgba(139,92,246,0.4) 100%
  );
  mix-blend-mode: multiply;
}
```

**4. Focal Point:**
- Always define focal point for cropping
- Faces should be in top 40% of frame
- Rule of thirds for composition
- Key subjects never centered (offset left/right)

**WOW Imagery Checklist:**
- [ ] Zero generic stock photos (no laptops on desks, no handshakes)
- [ ] All images have gradient overlays (for text readability)
- [ ] Images are WebP format with lazy loading

### PILLAR 6: MICRO-INTERACTIONS THAT DELIGHT

**Rule:** Interactions should feel like magic, not mechanics.

#### Button Hover States (Premium Tier)

**Never Acceptable:**
```css
/* This is lazy */
button:hover {
  background-color: blue;
}
```

**Minimum Acceptable:**
```css
button {
  transition: all 0.3s ease;
}
button:hover {
  background-color: var(--color-primary-dark);
  transform: translateY(-2px);
  box-shadow: 0 8px 16px rgba(0,0,0,0.2);
}
```

**WOW-Tier:**
```css
button {
  position: relative;
  overflow: hidden;
  transition: all 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}

/* Shine effect */
button::before {
  content: '';
  position: absolute;
  top: 0;
  left: -100%;
  width: 100%;
  height: 100%;
  background: linear-gradient(
    90deg,
    transparent,
    rgba(255,255,255,0.3),
    transparent
  );
  transition: left 0.5s ease;
}

button:hover::before {
  left: 100%;
}

button:hover {
  transform: translateY(-3px) scale(1.02);
  box-shadow: 0 12px 24px rgba(0,0,0,0.25);
}

button:active {
  transform: translateY(-1px) scale(0.98);
}
```

#### Scroll Reveal Animations

**Implementation:**
```css
/* Use Intersection Observer API */
.reveal {
  opacity: 0;
  transform: translateY(40px);
  transition: opacity 0.6s ease, transform 0.6s ease;
}

.reveal.active {
  opacity: 1;
  transform: translateY(0);
}

/* Stagger children */
.reveal-stagger > * {
  opacity: 0;
  transform: translateY(20px);
  transition: opacity 0.5s ease, transform 0.5s ease;
}

.reveal-stagger.active > *:nth-child(1) { transition-delay: 0.1s; }
.reveal-stagger.active > *:nth-child(2) { transition-delay: 0.2s; }
.reveal-stagger.active > *:nth-child(3) { transition-delay: 0.3s; }
```

#### Card Hover Effects

**WOW Card Hover:**
```css
.card {
  transition: all 0.4s cubic-bezier(0.4, 0, 0.2, 1);
  border: 1px solid rgba(0,0,0,0.1);
}

.card:hover {
  transform: translateY(-8px);
  box-shadow: 
    0 20px 40px rgba(0,0,0,0.15),
    0 0 0 1px rgba(0,0,0,0.05);
  border-color: var(--color-primary);
}

/* Gradient border reveal */
.card::before {
  content: '';
  position: absolute;
  inset: 0;
  border-radius: inherit;
  padding: 2px;
  background: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
  -webkit-mask: 
    linear-gradient(#fff 0 0) content-box, 
    linear-gradient(#fff 0 0);
  -webkit-mask-composite: xor;
  mask-composite: exclude;
  opacity: 0;
  transition: opacity 0.3s ease;
}

.card:hover::before {
  opacity: 1;
}
```

#### Link Underline Animations

**Standard (Boring):**
```css
a { text-decoration: underline; }
```

**WOW:**
```css
a {
  position: relative;
  text-decoration: none;
}

a::after {
  content: '';
  position: absolute;
  bottom: -2px;
  left: 0;
  width: 0;
  height: 2px;
  background: var(--color-primary);
  transition: width 0.3s ease;
}

a:hover::after {
  width: 100%;

```

#### Loading States

**Never Show:**
- Generic spinners
- "Loading..." text
- Blank white screens

**Always Show:**
- Skeleton screens (content placeholders)
- Progress indicators (if process is long)
- Optimistic UI (show result before confirmation)

**WOW Loading State:**
```css
/* Skeleton Screen */
.skeleton {
  background: linear-gradient(
    90deg,
    #f0f0f0 25%,
    #e0e0e0 50%,
    #f0f0f0 75%
  );
  background-size: 200% 100%;
  animation: loading 1.5s infinite;
  border-radius: 4px;
}

@keyframes loading {
  0% { background-position: 200% 0; }
  100% { background-position: -200% 0; }
}
```

**WOW Micro-Interactions Checklist:**
- [ ] All buttons have hover lift effect (translateY)
- [ ] Buttons have active press state (scale down)
- [ ] Links have animated underline (not default)
- [ ] Cards lift 8px+ on hover
- [ ] Scroll reveals use stagger delays (0.1s increments)
- [ ] Transitions use cubic-bezier easing (not linear)
- [ ] Loading states show skeletons (not spinners)
- [ ] Form inputs have focus states (outline + shadow)
- [ ] Icons have subtle rotation/scale on hover
- [ ] Page transitions fade in (not instant)

### PILLAR 7: CONTENT THAT CONVERTS

**Rule:** Every word must earn its place or be deleted.

#### Headline Writing Standards

**Bad Headlines (Generic, Forgettable):**
- "Welcome to Our Company"
- "Industry-Leading Solutions"
- "Your Trusted Partner"
- "Quality Service Since 1995"
- "We're Here to Help"

**Good Headlines (Specific, Benefit-Driven):**
- "Ship Features 10x Faster With AI-Powered Code Reviews"
- "Turn Customer Complaints Into Product Insights in Minutes"
- "Stop Losing Deals to 'We'll Think About It'"
- "Your Customers Don't Read Docs. Now They Don't Have To."

**WOW Headlines (Emotional, Unexpected):**
- "Build Like You Give a Damn"
- "Marketing That Doesn't Feel Like Marketing"
- "The CRM Your Sales Team Will Actually Use"
- "Stop Debugging. Start Shipping."
- "Design Systems That Don't Collect Dust"

**Formula for WOW Headlines:**
```
[Emotional Hook] + [Specific Outcome] + [Time Frame/Constraint]

Examples:
"Stop Wasting Weekends on Deployments" (fear + outcome + time)
"Turn Angry Customers Into Advocates in 24 Hours" (transformation + specific + time)
"Ship Your MVP Before Your Competitor Does" (urgency + outcome + competition)
```

#### Subheadline Standards

**Purpose:** Expand on headline, add proof/specificity

**Bad:**
"We provide comprehensive solutions for businesses of all sizes"

**Formula:**

```
[Social Proof] + [Specific Metric] + [Timeframe]
OR

```

#### CTA (Call-to-Action) Standards

**Banned CTA Text:**
- ❌ "Click Here"
- ❌ "Submit"
- ❌ "Learn More"
- ❌ "Get Started"
- ❌ "Sign Up"
- ❌ "Download Now"

**Acceptable CTA Text:**
- "See How It Works"
- "Start Your Free Trial"
- "Get Your Custom Quote"

**WOW CTA Text:**
- "Show Me The Magic ✨"
- "Yes, I Want This"

- "Claim My Free Audit"
- "Build My First Campaign"
- "Start Saving Time Today"

**CTA Principles:**
1. **First person** ("Build MY app" not "Build YOUR app")
2. **Outcome-focused** (what they get, not what they do)
3. **Urgency/Desire** (words like "now", "today", "claim")
4. **Specific** ("Start Free Trial" not "Get Started")

#### Body Copy Standards

**Readability Rules:**
- Sentences: 15-20 words maximum
- Paragraphs: 3-4 sentences maximum
- Line length: 60-70 characters
- Reading level: 8th grade or lower (use Hemingway Editor)

**Voice Guidelines:**

**Corporate (Avoid Unless Necessary):**
- "We leverage synergies to optimize stakeholder value"
- "Our solutions empower organizations"
- "Best-in-class enterprise-grade"

**Conversational (Use This):**
- "Here's what we built and why it matters"
- "This helps you do X without Y"
- "The problem: [pain]. The solution: [benefit]"

**Power Words to Use:**
- Transform, Unlock, Discover, Reveal
- Instantly, Effortlessly, Automatically
- Proven, Validated, Trusted
- Simple, Easy, Quick
- Exclusive, Limited, Rare

**Power Words to Avoid:**
- Synergy, Leverage, Optimize
- Robust, Comprehensive, Enterprise
- Leading, Innovative, Revolutionary (without proof)
- Quality, Professional, Excellent (vague)

#### Content Structure (F-Pattern Reading)

Users read in an F-pattern (top → left side → occasional horizontal sweeps)

**Optimize for F-Pattern:**
```
1. Most important info in first paragraph
2. Left-align all text (never center body copy)
3. Use subheadings every 3-4 paragraphs
4. Front-load paragraphs (key info first)
5. Use bullet points for scannability
```

**WOW Content Checklist:**
- [ ] Headlines are 8 words or less
- [ ] Headlines include specific outcome or benefit
- [ ] Subheadlines expand with social proof or metrics
- [ ] CTAs use first-person language ("My" not "Your")
- [ ] Body copy sentences are under 20 words
- [ ] Paragraphs are 3-4 sentences maximum
- [ ] No jargon or corporate buzzwords
- [ ] Reading level is 8th grade or lower (Hemingway test)
- [ ] Every section has clear hierarchy (H2 → H3 → body)
- [ ] Testimonials include specific outcomes (not just "great service")

### Responsive Design (Mobile-First)

**Breakpoint System:**
```css
/* Mobile First */
/* Base: 320px - 639px */

/* sm: 640px */
@media (min-width: 640px) { }

/* md: 768px */
@media (min-width: 768px) { }

/* lg: 1024px */
@media (min-width: 1024px) { }

/* xl: 1280px */
@media (min-width: 1280px) { }

/* 2xl: 1536px */
@media (min-width: 1536px) { }
```

**Mobile Optimization Rules:**
- Touch targets: 44px × 44px minimum
- Font sizes scale down 20-30% from desktop
- Spacing scales down 30-40% from desktop
- Navigation collapses to hamburger at < 768px
- Forms are single-column on mobile
- CTAs are full-width or prominent on mobile
- Images crop to focal point on mobile

- Interactive elements: 3:1 minimum

## SECTION 7: THE WOW WEBSITE AUDIT

### Run This Audit on Every Website Before Publishing

**5-Second Test:**
Show the website to someone for 5 seconds, then close it.

Ask them:
1. What does this company do?
2. What's the main benefit/value?
3. What should I do next (CTA)?

If they can't answer all 3, **redesign the hero section**.

---

**10-Second Emotion Test:**
Show the website for 10 seconds.

Ask them:
"How does this make you feel?"

Acceptable answers:
- "Impressed"
- "Excited"
- "Curious"
- "Confident"
- "Trusting"

Unacceptable answers:
- "Nothing"
- "Confused"
- "Bored"
- "Generic"
- "Okay, I guess"

If they give unacceptable answer, **increase visual impact**.

---

**Scroll Test:**
Scroll through the entire website at normal speed.

Count:
- How many times you stop scrolling to read (good)
- How many times you think "that's cool" (interactions)
- How many times you see generic stock photos (bad)

**Target:**
- Stops: 5+ per page
- "Cool" moments: 3+ per page
- Generic photos: 0

---

**Mobile Test:**
View on actual mobile device (not just browser DevTools).

Check:
- Can you tap all buttons easily?
- Is text readable without zooming?
- Do images look good (not cropped weird)?
- Is navigation intuitive?
- Does it feel "mobile-first" or "desktop-shrunk"?

If it feels like "desktop-shrunk", **redesign mobile layout**.

---

**Accessibility Test:**
1. Unplug your mouse
2. Navigate entire site with keyboard only (Tab, Enter, Escape)
3. Turn on screen reader (NVDA on Windows, VoiceOver on Mac)
4. Navigate first 3 sections

If any element is unreachable or confusing, **fix accessibility**.

---

**Performance Test:**
Run Lighthouse audit in Chrome DevTools.

**Required Scores:**
- Performance: 90+
- Accessibility: 95+
- Best Practices: 95+
- SEO: 95+

If any score is below target, **optimize before publishing**.

---

**Competitive Test:**
Find 3 competitor websites in the same industry.

Compare:
- Is our hero more impactful?
- Is our typography bolder?
- Are our images higher quality?
- Is our copy more specific?
- Are our interactions more delightful?

If we don't win 4 out of 5 categories, **we're not WOW enough**.
